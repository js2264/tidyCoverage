# tidyCoverage: Tidyomics-based analysis of coverage tracks over genomic features

The tidyCoverage package provides a bridge between Bioconductor
SummarizedExperiment objects and the tidyomics project.

## References

Serizay J, Koszul R., Epigenomics coverage data extraction and
aggregation in R with tidyCoverage. Bioinformatics 40, btae487 (2024).
[doi:10.1093/bioinformatics/btae487](https://doi.org/10.1093/bioinformatics/btae487)
